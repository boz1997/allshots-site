Baby showers

A baby shower photo app that also collects the messages

A baby shower is two things: the afternoon, and the keepsake. AllShots collects both — every guest’s photos in one album, and a memory book of notes and voice messages for the parents to open later.

By the AllShots team · Updated 21 September 2026

The photos

The host is busy hosting. The photos come from the guests — the gift-opening reactions, the game, the cake, the grandmother-to-be. One QR code on the gift table and the guests’ photos land in a shared album as they are taken. No app, no account; scanning the code opens the camera in the browser. Afterwards, download the whole album as a ZIP and send the link to anyone who could not make it.

The messages — a memory book for the baby

On the Medium and Unlimited plans, the same page that opens the camera also opens the memory book: guests write a note — advice, a wish, a story about the parents — and can record a voice memory, a spoken message the child can hear years from now in that person’s own voice.

It replaces the guest book with the pen that never works, and it captures the voices, which no card can.

A surprise for the parents

If the shower is a surprise, or if you want the album to be a gift, make it private: each guest sees only their own uploads, and the host sees everything. Hand over the album — photos, notes and voice messages — at the end of the afternoon or after the birth.

Setting it up

  1. Create the event on host.allshots.app. Choose open mode so guests can also upload from their camera roll.
  2. Pick Medium or Unlimited if you want the memory book and voice memories.
  3. Download the QR code and print it: one on the gift table, one on the food table.
  4. Add a line to the invitation: “Scan the code at the shower to add your photos and leave a message for the baby.”

Questions people ask

What is the memory book?

A page where guests write a note for the parents or the baby, from the same link as the camera. On Medium and Unlimited events guests can also record a spoken voice memory.

Do guests need an app?

No. The QR code opens the camera and the memory book in their browser. iPhone users may use the app, but it is optional.

Can the album be a surprise gift?

Yes. Make the album private so guests see only their own uploads, then share the full album — photos, notes and voices — when you choose.

Can I download the voice messages?

Yes. The host can download the photos as a ZIP and the voice memories as a separate ZIP from the event page.
